# 梅花觀象｜手機 PWA 版 v1.2.0

## 最快的手機使用方式

用手機開啟已發布的工具網址，等待畫面上方顯示「已可離線使用」。

- iPhone／iPad：使用 Safari 開啟 → 分享 → 加入主畫面 → 若出現「以網頁 App 開啟」，保持開啟 → 加入。
- Android：使用 Chrome 開啟 → 按工具內的「安裝到手機」。若沒有跳出安裝視窗，用 Chrome 選單 → 安裝應用程式／新增至主畫面。
- 安裝完成後，從主畫面開啟「梅花觀象」。首次仍請連線，待離線準備完成再關閉網路。

離線可起卦、查看卦象、複製解盤文字、儲存紀錄、回填結果及匯出 JSON。將文字貼給線上 AI 解盤、閱讀外部原典則需要網路。

## 上傳 GitHub Pages

1. 解壓 ZIP，將所有檔案與 `icons` 資料夾完整上傳至儲存庫根目錄，或同一個子資料夾。
2. 保留 `index.html`、`style.css`、`engine.js`、`app.js`、`pwa.js`、`sw.js`、`manifest.webmanifest` 與 `icons/` 的相對位置。
3. 儲存庫 Settings → Pages → 選擇發布分支與目錄。
4. 用手機開啟 GitHub 提供的 **HTTPS** 網址，待顯示「已可離線使用」後加入主畫面。

直接從手機檔案 App 點開 `index.html`，不等於安裝 PWA。PWA 安裝與離線快取需要 HTTPS 網址；另提供的 `Meihua-Yishu.html` 是不需其他檔案的單檔版本，可在支援執行本機 HTML 的瀏覽器中開啟。iOS 檔案預覽可能不執行 JavaScript，手機請使用線上 PWA。

## 原有功能

- 國曆、台灣時間起卦，自動換算農曆；可選 00:00 或 23:00 換日。
- 三數起卦（第三數獨立取動爻）。
- 本卦、互卦、變卦、動爻與體用五行。
- 「複製給 AI 解盤」包含完整輸入、算式、卦象、體用與實際觀察內容。
- 自動複製受限時顯示全文供手動選取。
- 本機觀察紀錄、事後回填、JSON 匯出／匯入，與 v1.0 備份相容。

## 紀錄與更新

紀錄只存在目前裝置與瀏覽器，不會自動同步到其他裝置。不同瀏覽器、不同網址、某些系統中的主畫面 App 可能有獨立儲存空間；若安裝後沒有看到原紀錄，請從原本版本匯出 JSON，再到新版本匯入。

有新版時會顯示「新版已備妥」。先儲存紀錄再點選，工具才會重新載入新版。更新程式只清理本工具的舊版快取，不清除觀察紀錄。

離線狀態須以頁面顯示為準。如果首次下載尚未完成，或瀏覽器清除了網站資料，請連線重新開啟。瀏覽器可能因裝置空間不足清理本機資料，請定期匯出 JSON。

## 起卦約定

時間固定為台灣 UTC+8；年支依農曆年，閏月沿用原月數，分鐘不另加數；不採真太陽時。支援 1900–2100 年。

互卦一律取本卦第 2–4 爻、第 3–5 爻，純乾純坤亦同。體為本卦不動的三爻卦，變卦沿用本卦體卦。畫面的卦意為白話觀察線索，完整原典與起卦規則可從頁尾查看。
